# 酒馆助手（Tavern Helper / JS-Slash-Runner）插件本体

> 仓库：<https://github.com/n0vi028/JS-Slash-Runner>（N0VI028，1158 stars，TypeScript，main 分支）
> 官方文档：<https://n0vi028.github.io/JS-Slash-Runner-Doc/>（**最权威接口文档**）
> 许可证：Aladdin

## 它是什么

在 SillyTavern 中**渲染前端界面 + 运行 JS 脚本**的扩展。ST 默认不执行 JS，酒馆助手通过 **iframe 隔离执行**脚本，让角色卡能带交互界面、状态栏、音效等。

## 核心能力（官方文档首页归纳）

- 🎨 **界面渲染**：对话中渲染完整 HTML/CSS/JS 界面，自动获取用户头像，自定义加载动画
- 🛠️ **脚本系统**：全局脚本、脚本库；内置 jQuery、Lodash 等第三方库
- 🌏 **世界书操作**：世界书/条目的增删改查
- 📝 **变量系统**：变量增删改查，提示词中直接取变量
- 🤖 **AI 生成控制**：自定义生成配置与提示词、流式传输、覆盖/注入提示词
- 🔄 **事件系统**：监听酒馆内置事件、自定义事件、事件等待与一次性监听
- ⚡ **实用功能**：触发 slash 命令、管理酒馆正则、操作楼层消息和 iframe
- 🔌 **系统交互**：与 ST 界面交互、钩子；可作为中间层连接外部应用（socket.io-client）
- 🎵 **音频系统**：BGM 与音效播放、多种播放模式

## 典型用途

1. 把状态栏代码块美化成动态 HTML 界面
2. 监听现实时间/酒馆事件做 meta 游戏、多媒体播放、自制游玩界面
3. 用 jQuery 给预设条目加按钮等 UI 增强
4. 定期后台调 LLM 总结剧情
5. 连接外部服务器，实现外部程序与酒馆通信

## ⚠️ 安全风险（官方警告）

可执行任意 JS：恶意脚本可窃取 API 密钥/聊天记录、破坏设置。执行前检查脚本来源与内容。

## 开发相关（README）

- `dist/` 直接随仓库分发（CI 重新打包），`.gitattributes` 对 dist 冲突取当前版本
- 编译：Node 22+，`npm i -g pnpm` → `pnpm install` → `pnpm build`；`pnpm watch` 持续编译，刷新酒馆即生效
- 项目放在 ST 目录外构建时用环境变量 `ST_IMPORT_DEPTH=<层级数>` 指定相对深度（标准第三方扩展结构为 5）
- 部署产物：`dist/`、`lib/`、`i18n/`、`manifest.json` → ST 扩展目录（或符号链接）
