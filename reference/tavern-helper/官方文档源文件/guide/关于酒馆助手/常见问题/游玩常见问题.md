# 游玩常见问题

即使成功安装了酒馆助手, 仍然无法正常游玩角色卡?

以下内容基于络络的总结, 做了部分修改, 感谢分享!

[![](https://img.shields.io/badge/Discord-%E7%BB%9C%E7%BB%9C-gray?style=for-the-badge&logo=discord&logoColor=white&labelColor=5865F2
)](https://discord.com/channels/1134557553011998840/1324937235623051385)

在提问前请务必先进行自查. 创作者们都是在为爱发电, 写卡的初衷是满足创作欲而非提供客服服务😭. 因此, **提问时请注意礼貌, 同时可以适当表达对作者作品的喜爱**——这是支持创作者继续创作的动力!

**提问时候一定要包含以下内容:**

- 直接的完整截图
- 点开信息右上角钢笔图标编辑按钮的截图
- 文字描述问题的前因后果: 如何触发、具体表现、导致后果和已经尝试过的方法

在提问之前请根据此指南进行自查, 如果问题仍然存在, 再对作者进行提问, 来避免被问及指南内包含的事项. (前提是你真的自查完整了!)

## 前端卡游玩常见问题

### 1. 只有文字/代码块, 没有界面是怎么回事?

根据[前端显示问题自查建议](#前端显示问题自查建议), 逐项排查.

### 2. 流式生成过程中能看到文字/代码块, 但输出完成后应该出现界面的位置直接空白是怎么回事?

- 你的酒馆助手版本过低，而作者使用了高版本的功能导致界面无法加载.
- 代码加载出错或者前端界面的尺寸问题, 需要直接联系角色卡/脚本作者.

### 3. 太卡了/加载好久啊?

建议在设置中限制加载消息条数 (如设置为 5 条), 同时将酒馆助手的"启用代码折叠"和"取消前端代码高亮"开启, 以避免过多消息或大量的未渲染代码块导致系统卡顿.

### 4.为啥我刚才明明正常显示画面了, 聊了几楼回去看又不正常了?

- 你设置了酒馆助手渲染器的渲染深度.
- 作者设定了正则的处理深度, 将更早的聊天记录取消渲染或整理简化 (目的一般为防止卡顿), 可自行修改正则的处理深度, 也可查看发布帖关于此的描述或询问作者.
- 总结插件或者脚本处理了历史楼层.

### 5. 为啥出现了两次一样的界面

油猴HTML注入器/Gemini轮询/小白X等拥有前端渲染功能的插件, 也会再渲染一次代码内容, 导致出现两个相同界面, 请酌情关闭对应功能.

### 6. 界面闪烁了一下之后就消失了/和界面交互后界面消失了

检查是否开启了油猴脚本 HTML 注入器或 Gemini轮询插件的 HTML 注入器, 如果开启了请关闭.

### 7. 其他可能出现的显示问题

查看下方的[前端显示问题自查建议](#前端显示问题自查建议).

## 前端显示问题自查建议

如扩展安装成功但界面显示失败, 请参考以下内容进行自查:

### 0.API与模型自查

- 小心部分淘宝商/其他中小渠道商可能会在所谓的 Claude API 或其他 API 中灌水, 在后台更换为性能更低的模型, 导致难以执行前端卡复杂的指令. 如果你是这些渠道请检查自己的模型, 并去询问服务商.
- 部分具有外审的模型 (例如 Gemini) 会在检查到敏感内容时截断输出, 导致最终结果不完整, 进而无法匹配正则, 造成界面渲染失败. 如果你使用了这些模型, 请尝试更换模型或关闭流式输出.

### 1. 酒馆助手配置

- 确保安装最新版本酒馆助手
- 可以删除并再次使用安装扩展进行安装, 设置不会丢失

### 2. 酒馆助手基础设置调整

#### 必要开启项

- 开启【**酒馆助手-渲染**】

#### 必要关闭项

- 关闭【与角色卡或目标功能无关的**酒馆助手脚本**】, 部分脚本会修改消息内容或干扰界面渲染
- 关闭【**允许流式渲染**】(酒馆助手-渲染-实验功能), 可能导致界面渲染异常

### 3. 第三方插件相关调整

- 关闭【油猴脚本HTML注入器/Gemini轮询/小白X等拥有**前端渲染功能的插件或脚本**】
- 关闭【酒馆聊天**自动翻译插件**和浏览器的**自动翻译**】
- 关闭【提示词模板】插件的【先处理原始内容】选项
- 尽可能禁用**第三方插件**, 仅保留角色卡必需的插件

> 开启HTML代码注入器可能导致前端界面闪烁、消失、重复等多种错误.

### 4. 美化相关调整

- 切换回【酒馆默认主题】, 排除自定义美化 (主题/用户 CSS) 的干扰

> 部分美化会遮挡界面、破坏样式或与前端卡冲突, 确认恢复正常后再逐个开启测试

### 5. 预设相关调整

- 关闭预设中的**COT (思维链)**
- 关闭预设中要求生成**状态栏**的条目
- 关闭或修改预设中对正文要求了**特殊格式**的条目

> 这些具有提供格式的功能大概率会与前端卡产生冲突, 建议全部关闭, 在能正常渲染界面后, 再逐个开启测试稳定性.

如仍然遇到格式问题, 建议询问预设作者.

### 6. 正则相关调整

- 界面可能来自全局正则、局部正则或预设正则, 排查时建议关闭目标范围以外的正则, 再逐个开启找出问题所在:
  - **全局正则**: 每个聊天都会出现的界面
  - **局部正则**: 角色卡单独的界面
  - **预设正则**: 跟随预设的界面
- 正则如有复数个, 其执行顺序为从上到下, 若对其顺序进行了更改, 可能导致界面不能正常渲染

### 7. 世界书确认

- 确保角色卡中的世界书正确导入
- 点击角色卡详情页中的小地球图标, 使其处于点亮状态
- 不要将其他角色的专有世界书设置到【**全局世界书**】
- 关闭全局世界书中要求生成**状态栏**的条目, 可能对前端卡的格式产生干扰

### 8. 版本检查

- 推荐使用最新版本的酒馆

### 9. 浏览器兼容性

- 可尝试更换浏览器
- 推荐使用 Chrome、Edge 等主流浏览器
- 某些国产浏览器无法运行 Blob 渲染, 因此会出现渲染为空的情况. 可关闭【使用 Blob 渲染】选项, 或直接更换浏览器

### 10. 终极解决方案

- 如果以上方法都无效, 可以尝试重新部署酒馆并重复以上步骤

> 注: 重新部署较为繁琐, 建议先在社区寻求帮助, 无果后再考虑此方案
