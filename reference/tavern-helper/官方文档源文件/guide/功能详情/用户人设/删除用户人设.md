## deletePersona

删除 `persona_id` 用户人设

```ts
function deletePersona(persona_id: LiteralUnion<'current', string>): Promise<boolean>;
```

### 参数

#### persona_id

- **类型**: `string`
- **描述**: 用户人设名称、唯一 id 或 `'current'`

### 返回值

- **是否成功删除**: `boolean`; 可能因用户人设不存在或名称不唯一等原因而失败

### 异常

- 如果访问后端失败, 将会抛出异常
