## getPersonaAvatarPath

获取用户人设的头像路径

```ts
function getPersonaAvatarPath(persona_id?: LiteralUnion<'current', string>): string | null;
```

### 参数

#### persona_id

- **类型**: `string`
- **描述**: 用户人设名称、唯一 id 或 `'current'`; 不填则默认为 `'current'`

### 返回值

- **用户人设头像路径**: `string | null` - 可直接用于 `img` 标签的 `src` 属性, 如果用户人设不存在或名称不唯一, 则返回
  `null`

## getPersona

获取 `persona_id` 用户人设的内容

:::code-group

```ts [getPersona]
function getPersona(persona_id: LiteralUnion<'current', string>): Persona;
```

```ts [Persona]
type PersonaConnection = {
  type: 'character' | 'group';
  id: string;
};

type Persona = {
  avatar_id: string;
  avatar: `${string}.png` | Blob;
  name: string;
  title: string;
  description: string;
  position: number;
  depth: number;
  role: number;
  lorebook: string;
  connections: PersonaConnection[];
  is_default: boolean;
};
```

:::

### 参数

#### persona_id

- **类型**: `string`
- **描述**: 用户人设名称、唯一 id 或 `'current'`

### 返回值

- **用户人设内容**: [`Persona`](#getpersona)

### 异常

- 如果用户人设不存在或名称不唯一, 将会抛出异常
