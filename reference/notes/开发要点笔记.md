# 开发要点笔记（实战踩坑总结）

> 本项目（NPC资料表生成器 + 命令面板）开发过程中验证过的经验，写新插件时直接抄作业。

## 1. 脚本按钮（入口按钮的标准做法）

```js
// 注册按钮到酒馆助手按钮栏（与"简易开场白选择"同款位置）
appendInexistentScriptButtons([{ name: '按钮名', visible: true }]);
// 监听点击
eventOn(getButtonEvent('按钮名'), () => { /* 打开面板 */ });
```
- 兜底方案：往 `#rightSendForm` / `#form_sheld` 注入 div 按钮
- 环境探测：`typeof appendInexistentScriptButtons === 'function'`

## 2. 执行酒馆 slash 命令

```js
await triggerSlash('/hide 3');   // 官方接口，与手打等效
```
- 命令写错**不会有任何反馈**，参数语法先查命令手册
- ⚠️ `/sendas` 走 slash 管道会出现"楼层发出但正文为空"的 bug，
  应改用 `createChatMessages([{name, role:'assistant', message}])` 直写

## 3. AI 生成

```js
// 走酒馆当前预设 + 当前连接 API，自己的指令用 injects 注入
await generate({ user_input, injects: [{ role:'system', content, position:'in_chat', depth:0, should_scan:false }], should_silence: true });

// 完全自定义提示词（不套预设）
await generateRaw({ ordered_prompts: [{role:'system',content},{role:'user',content}] });

// 自填 OpenAI 兼容 API（generate/generateRaw 都支持）
custom_api: { apiurl, key, model, source: 'openai' }

// 只读模型列表（不发测试请求）
const list = await getModelList({ apiurl, key });
```

## 4. 世界书

- 旧版 lorebook 系列已 `@deprecated`，用新版：
  - `getWorldbookNames()` 所有世界书名
  - `getCharWorldbookNames('current')` → `{ primary, additional }`（可能为 null）
  - `getOrCreateChatWorldbook('current')` 聊天世界书
  - `createWorldbookEntries(name, [条目])` 新增条目
  - `getWorldbook(name)` / `updateWorldbookWith(name, fn)` / `replaceWorldbook(...)`
- 条目结构见 `接口定义/worldbook.d.ts` 的 `WorldbookEntry`（绿灯=`strategy.type:'selective'`+keys；防递归=`recursion.prevent_incoming/prevent_outgoing:true`）

## 5. 消息 / 变量

- `getChatMessages(-1)` 取最新楼层；`createChatMessages` / `setChatMessages` / `deleteChatMessages`
- 设置持久化：`getVariables({type:'script'})` / `updateVariablesWith(fn, {type:'script'})`（脚本变量区，适合存 API 配置）

## 6. UI 界面

- 脚本运行在 iframe 里，界面要挂到酒馆主页面：
  ```js
  const doc = (() => { try { return window.parent.document } catch { return document } })();
  ```
- ⚠️ 渲染日志等要用 `doc.querySelector` 而不是 `document`（踩过：用错导致日志永远不显示）
- 更新脚本时先 `doc.getElementById(id)?.remove()` 清旧实例，否则跑的还是旧界面
- **事件绑定放在一切初始化之前**，任何初始化报错都不会拖垮按钮
- 拖动用 `mousedown/mousemove/mouseup + touch*` 事件，**别用 Pointer Events**（部分 WebView 不支持）
- 整个脚本包 `(async () => { ... })().catch(e => console.error(...))`，启动失败给个可见的 ❗ 提示

## 7. 工程习惯

- 每步操作都写日志（可折叠 `<details>`），出错自动展开——方便用户截图反馈
- 危险操作（删除楼层等）在按钮注释里标"危险操作，不可撤回"
- 等环境就绪：轮询 `typeof 接口名 !== 'function'`，15 秒超时放弃
- 纯前端单文件即可，无需构建
