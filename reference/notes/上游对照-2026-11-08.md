## 结论先行

**产物运行时代码零改动**。`TAVERN_API.md` 契约表所列接口（getCharacter / getChatMessages / setChatMessages / triggerSlash / getLorebookEntries / getWorldbook / eventOn / appendInexistentScriptButtons / getButtonEvent / playAudio 系列）在 4.6.3 → 4.11.3 之间均无破坏性变更；工具源码未用到任何被改名/改型的 API（`insertAudioList→appendAudioList`、`findCharacterIndex→findIndex`、`trim_strings: string→string[]` 均不涉及），`getCurrentAudio`（4.8.8 新增）本就有 `typeof` 守卫。

## SillyTavern 1.19.0 侧实测核对（源码 grep）

| 早前分析的说法 | 核对结果 |
| --- | --- |
| 消息 HTML 过 DOMPurify | ✅ `public/script.js` `DOMPurify.sanitize(mes, config)`，config 含 `MESSAGE_SANITIZE: true`、`ADD_TAGS: ['custom-style']` |

| 「在响应中显示标签」设置会把 HTML 转义为纯文本 | ⚠️ 设置存在（zh locale 949 行 `"Show tags in responses": "在响应中显示标签"`）；转义行为未逐行核实，入自检清单时标「待真机验证」 |
| 移动端断点 1000px | ✅ `public/css/mobile-styles.css` `@media screen and (max-width: 1000px)` |
| custom_api.source 常量 | ✅ `src/constants.js` 含 `CUSTOM: 'custom'`；`常用资料链接.md` 的钉行号链接已改为不钉行 |
