# SillyTavern 官方中文文档

> 仓库：<https://github.com/intellecat/SillyTavern-Docs-ZH>
> 103 stars，语言 CSS（retype 文档站构建）

## 项目说明

SillyTavern 官方英文文档（docs.sillytavern.app）的**社区中文翻译版**，用 [retype](https://retype.com/) 构建，可本地起站或直接在线阅读。仓库本身就是完整的文档站源码。

## 仓库结构（即文档目录）

| 目录 | 内容 |
| --- | --- |
| `Installation/` | 安装（Windows / Linux / Mac / Termux / Docker 等） |
| `Usage/` | 核心用法：角色卡、世界书、预设、提示词、指令模式等 |
| `Administration/` | 管理与配置（config.yaml、多用户、远程访问等） |
| `extensions/` | 扩展文档 |
| `For_Contributors/` | 贡献者指南（含 Function Calling 等） |
| `readme.md` | 项目 README（ST 简介、分支说明、主要功能、扩展列表） |

## README 要点（原文留档 `99-原文抓取/SillyTavern-Docs-ZH-readme.md`）

- SillyTavern 是基于 SillyTavern 前端衍生的用户界面，专注**角色扮演与故事创作**
- 介绍分支区别：`release` 稳定 / `staging` 最新功能
- 角色卡片说明（PNG 卡、JSON 卡）
- 主要功能：提示词管理、世界书、指令模板、群聊、扩展生态等

## 使用建议

- 查功能概念/安装问题优先看此中文文档
- 查最新特性仍以英文官方文档 <https://docs.sillytavern.app/> 为准（翻译可能滞后）
- 需要离线阅读时可直接 clone 本仓库，`readme.md` 单文件也可当 ST 总览阅读
