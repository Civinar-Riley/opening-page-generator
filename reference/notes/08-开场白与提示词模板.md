# 开场白与提示词模板

---

## 1. 开场白写法

### 1.1 核心原则

#### 一致性原则
- **符合设定**: 开场白必须严格符合世界书的世界观设定
- **符合角色**: 角色行为、语言、性格必须与角色卡描述一致
- **符合格式**: 必须严格按照美化正则约束的格式输出

#### 质量原则
- **场景代入感强**: 让用户能够立即进入角色
- **互动性强**: 为用户留下足够的回应空间
- **细节丰富**: 包含环境描写、角色动作、对话等要素

### 1.2 格式要求

开场白的格式必须与**美化正则约束的格式完全一致**。

#### XML 标签格式示例
```xml
<UI>
<story>
晨光透过雕花窗棂洒进书房，在紫檀木书桌上投下斑驳的光影。

苏月瑶身着月白色长袍，乌黑的长发用一支玉簪简单挽起。她正专注地批阅着案上的文书，笔尖在宣纸上轻轻划过。

听到脚步声，她缓缓抬起头，澄澈的眼眸中闪过一丝惊讶，随即化为温和的微笑："阁下是？怎么会来到我的书房？"
</story>
<char>
[苏月瑶|青云派掌门之女|修为:筑基后期|心情:平和|好感度:50]
</char>
<options>
[在下是...][失礼了，偶然闯入...][久闻苏姑娘大名...]
</options>
</UI>
```

### 1.3 创作流程

#### 第一步：收集必要信息
| 信息类别 | 需要确认的内容 |
|---------|--------------|
| **世界观** | 世界背景、时间、地点、氛围 |
| **角色** | 姓名、性格、外貌、背景、当前状态 |
| **格式** | 输出格式要求、标签结构 |

#### 第二步：设计开场场景
1. 选择时间地点
2. 设定情境
3. 规划冲突/互动点
4. 考虑多个场景

#### 第三步：撰写开场白内容

**字数要求**: 300-600字

**内容要素**:
1. **环境描写** (20-30%): 描绘场景氛围
2. **角色描写** (20-30%): 外貌细节、动作姿态
3. **对话/互动** (30-40%): 角色的第一句话
4. **留白空间** (10-20%): 为用户回应留下空间

### 1.4 多开场白创作

#### 场景差异化设计
| 维度 | 变化方式 |
|------|---------|
| **时间** | 早晨、中午、傍晚、深夜 |
| **地点** | 室内、室外、私密、公开 |
| **情境** | 主动、被动、中立 |
| **情绪基调** | 轻松、严肃、神秘、温馨 |

#### 文件结构
```
[角色名]_开场白.txt

=== 开场白 1：[场景名称] ===
[开场白1内容]

=== 开场白 2：[场景名称] ===
[开场白2内容]
```

### 1.5 质量检查清单

- [ ] 字数在300-600字范围内
- [ ] 符合世界书世界观设定
- [ ] 符合角色性格和背景
- [ ] 严格遵循美化正则约束的格式
- [ ] 内容有吸引力，能够引发用户回应
- [ ] 格式结构完整，标签正确

## 2. 提示词模板系统

### 2.1 什么是提示词模板

提示词模板语法允许在世界书、预设、QR、角色定义等各种地方写 JavaScript 代码，用变量、条件判断逻辑等控制提示词是否发送给 LLM。

### 2.2 核心功能

1. **动态变量**: 为角色设置好感度、亲密度等数值
2. **条件判断**: 根据变量值决定 AI 看到什么内容
3. **阶段切换**: 不同阶段展示不同的人设和行为指导

### 2.3 变量系统

#### 变量定义
```yaml
变量:
  角色名:
    变量名: '{{getvar::变量.角色名.变量名}}'
```

#### 变量使用
```
亲密度：{{getvar::变量.络络.亲密度}}
```

### 2.4 EJS 条件判断

#### 基础语法
```ejs
<%_ if (条件) { _%>
  条件为真时的内容
<%_ } else if (条件) { _%>
  条件为假时的内容
<%_ } _%>
```

#### 完整示例
```yaml
---
<%_ const 亲密度 = getvar('变量.络络.亲密度'); _%>
<%_ if (亲密度 < 20) { _%>
  角色指导：目前络络对{{user}}并不熟悉，络络应该对USER很冷淡。
  变化倾向：随着亲密度增加，络络会变得更加关心。
<%_ } else if (亲密度 >= 20 && 亲密度 < 50) { _%>
  角色指导：络络开始对{{user}}产生好感，开始主动关心{{user}}。
  变化倾向：随着亲密度增加，络络会变得爱上{{user}}。
<%_ } else if (亲密度 >= 50) { _%>
  角色指导：络络对{{user}}产生爱意，开始主动关心{{user}}。
<%_ } _%>
```

### 2.5 变量更新规则

```yaml
rule:
  availability: only use variables listed in `变量` document, don't fabricate new variables
  name: consists of full path from root to leaf node and demilited by '.', such as `变量.络络.亲密度`
  check list:
    - Update '亲密度' by ±(3~7) according to characters' attitudes towards <user>'s behavior
    - Update '当前时间阶段' for time progression
```

### 2.6 输出格式

```yaml
format: |-
  <UpdateVariable>
  <Analysis>
  ${
    - 分析变量变化
    - 检查条件是否满足
  }
  </Analysis>
  @${variable}=${old}⇒${new}@
  </UpdateVariable>
```

## 3. 世界书编写要点

### 3.1 条目类型

#### 常驻激活条目
```json
{
  "comment": "世界基础",
  "constant": true,
  "content": "世界基础设定..."
}
```

#### 关键词触发条目
```json
{
  "comment": "青云门",
  "constant": false,
  "key": ["青云门"],
  "content": "青云门简介..."
}
```

### 3.2 递归防护

**必须设置**:
```json
{
  "excludeRecursion": true,
  "preventRecursion": true
}
```

### 3.3 化整为零原则

**推荐**: 将世界书拆成细小详细的条目，利用关键词激活

**优势**:
- 降低总激活 Token
- 提高精准度
- 灵活可控
- 节省成本

### 3.4 条目框架

#### 世界类条目
| 类别 | 条目建议 | 关键词示例 |
|------|---------|-----------|
| 总览 | 世界基础 | `[]`（常驻） |
| 地理 | 地理概况 | `["地理","地区"]` |
| 势力 | 主要组织 | `["组织名"]` |
| 规则 | 特殊规则 | `["规则","限制"]` |

#### 角色类条目
| 类别 | 条目建议 | 关键词示例 |
|------|---------|-----------|
| 总览 | 角色总览 | `["角色名"]` |
| 外貌 | 外貌特征 | `["外貌","长相"]` |
| 语言 | 语言风格 | `["说话","语气"]` |
| 行为 | 行为方式 | `["行为","动作"]` |

## 4. 正则配合

### 4.1 变量初始化正则
```txt
脚本名称: 变量-初始化
查找正则表达式：\|初始化变量\|
替换为：
<UpdateVariable>
@变量.角色名.亲密度=0@
@变量.角色名.好感度=0@
</UpdateVariable>
```

### 4.2 变量设置正则
```txt
脚本名称: 变量-设置变量
查找正则表达式：/@(.*?)@?=(?:.*?⇒)?'?(.*?)'?((@$)|(?=@))/gm
替换为：{{setvar::$1::$2}}
```

### 4.3 隐藏变量更新
```txt
脚本名称: 变量-隐藏变量更新
查找正则表达式：/<UpdateVariable>.*?(?:<\/UpdateVariable>|$)/gs
替换为：(留空)
```

## 5. 完整示例

### 5.1 变量世界书条目
```yaml
---
变量:
  络络:
    亲密度: '{{getvar::变量.络络.亲密度}}'
    当前时间阶段: '{{getvar::变量.络络.当前时间阶段}}'
    是否添加微信好友: '{{getvar::变量.络络.是否添加微信好友}}'
rule:
  availability: only use variables listed in `变量` document
  name: consists of full path from root to leaf node
  check list:
    - Update '亲密度' by ±(3~7) according to characters' attitudes
    - Update '当前时间阶段' for time progression
```

### 5.2 角色阶段世界书条目
```yaml
---
角色阶段:
  描述: 经过剧情发展后角色成长得到的新人设
  关联变量: 各角色的阶段关联有不同的变量
  角色指导: 角色在这个阶段会采取的行为和态度
  变化倾向: 随着associated variable接近下一阶段，角色逐渐发生的变化

络络:
  关联变量: 亲密度({{getvar::变量.络络.亲密度}})
  阶段名称:
    阶段1: 暗中观察(20以下)
    阶段2: 谨慎靠近(20~39)
    阶段3: 敞开心扉(40~59)
    阶段4: 依恋信任(60~79)
    阶段5: 永恒的爱(79~100)

<%_ const 亲密度 = getvar('变量.络络.亲密度'); _%>
<%_ if (亲密度 < 20) { _%>
  角色指导：目前络络对{{user}}并不熟悉，络络应该对USER很冷淡。
<%_ } else if (亲密度 >= 20 && 亲密度 < 50) { _%>
  角色指导：络络开始对{{user}}产生好感，开始主动关心{{user}}。
<%_ } else if (亲密度 >= 50 && 亲密度 < 80) { _%>
  角色指导：络络对{{user}}产生爱意，开始主动关心{{user}}。
<%_ } else if (亲密度 >= 80) { _%>
  角色指导：络络会对{{user}}表白，变得死心塌地。
<%_ } _%>
```

## 6. 总结

### 开场白要点
1. 收集信息: 确认世界观、角色、格式要求
2. 设计场景: 创建引人入胜的开场情境
3. 撰写内容: 300-600字，包含环境、角色、互动
4. 遵循格式: 严格使用美化正则约束的格式
5. 多开场白: 生成2-4个不同场景

### 提示词模板要点
1. 变量系统: 定义和初始化变量
2. 条件判断: 使用 EJS 控制内容输出
3. 变量更新: AI 自动更新变量值
4. 正则配合: 隐藏变量更新过程
