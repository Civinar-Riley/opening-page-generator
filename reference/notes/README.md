# 酒馆助手插件开发资料包

给"下次想写酒馆助手插件"的自己准备的资料，全部来自本项目实战验证。

## 目录结构

```
酒馆助手插件开发资料/
├─ 教程-AI插件开发提示词.md   ← 纯奶龙 vibe coding 教程（两段式提示词模板）
├─ 常用资料链接.md            ← 官方文档 / 命令手册等所有链接
├─ 开发要点笔记.md            ← 实战踩坑总结，写新插件直接抄作业
├─ 接口定义/                  ← 酒馆助手全部接口 .d.ts（带中文注释，喂给 AI 用）
│   ├─ index.d.ts             ← 总入口：所有可用函数一览
│   ├─ generate.d.ts          ← AI 生成（generate / generateRaw / 自定义API）
│   ├─ worldbook.d.ts         ← 世界书读写（新版）
│   ├─ chat_message.d.ts      ← 聊天楼层增删改查
│   ├─ variables.d.ts         ← 变量（脚本设置持久化）
│   ├─ script.d.ts            ← 脚本管理
│   └─ ...                    ← 角色卡 / 预设 / 正则 / 宏等其余接口
└─ 示例脚本/
    ├─ 酒馆助手脚本-简易开场白选择v0.2.json  ← 社区脚本（脚本按钮注册的参考实现）
    ├─ NPC资料表生成器.js                    ← 自制：表单→AI生成→写世界书
    └─ 命令面板.js                           ← 自制：slash命令可视化按钮面板
```

## 下次写插件的推荐流程

1. 打开 `教程-AI插件开发提示词.md`，套用两段式提示词开帖
2. 把 `接口定义/` 整个文件夹发给 AI
3. 让 AI 写代码前，先让它看 `开发要点笔记.md` 里的踩坑总结（能少走弯路）
4. 代码粘贴进酒馆助手新脚本 → 启用 → 测试 → 报错截图回喂 AI
