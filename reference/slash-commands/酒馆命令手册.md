## 使用须知

- 数据类型：Number / boolean / String / Varname / List / Dictionary / Subcommand / **closure**（推荐，包裹在 `{:` `:}` 之间，延迟求值，作子命令时无需转义管道和宏）
- 命令输出通过 **pipe（管道 `|`）** 传给下一条命令；`{{pipe}}` 宏取上一条结果
- `||` 阻止上一条输出自动注入下一条
- 闭包序列化：`/closure-serialize`、`/closure-deserialize`（可存入变量）

## 高频命令速查（含语法摘录）

```text
/setvar key=名 index=0 value     # 局部变量（聊天元数据），index 写数组/对象
/getvar key=名                    # 取值 → pipe；宏写法 {{getvar::名}}
/setglobalvar key=名 value        # 全局变量（settings.json）
/if left=A right=B rule=eq {:/echo 相等:} else={:/echo 不等:}
/while left=i right=10 rule=lt {:/addvar key=i 1:}   # guard 默认限 100 次
/times 5 {:/echo {{timesIndex}}:}                    # 循环 5 次
/gen [length=200] 提示词           # 用 LLM 生成 → pipe
/genraw 提示词                     # 裸生成（不含角色卡/世界书）
/inject id=x position=chat depth=4 内容   # 提示词注入（可覆盖同 id）
/echo [severity=warning] [timeout=4000] 文本     # Toast 提示
/popup [wide] [okButton="OK"] 文本              # 阻塞式弹窗，支持 HTML
/buttons labels=["A","B"] 继续？                 # 按钮 → 返回所点项
/input default="默认值" 标题                     # 输入框 → 返回输入
/replace find=旧 replace=新 {{pipe}}  /match /test
/regex find=/pattern/flags replace=新 {{pipe}}
/css-var name=--color value=#fff   # 脚本改 CSS 变量（做动态主题）
/theme default | /bubble | /flat | /vn | /panels    # 切换 UI 风格
/bg 背景.png                        # 切换背景图（主题脚本常用）
/movingui 自定义方案名              # 移动 UI 面板布局
/roll 1d20                          # 骰子（需 Dice 扩展）
/event-emit event=名 data=数据      # 发自定义事件（配合酒馆助手监听）
```

## 对主题/脚本开发最相关的命令组

- `/css-var`、`/theme`、`/bg`、`/movingui` —— 运行时操控 UI
- `/popup`、`/buttons`、`/input` —— 交互面板
- 变量全家桶 + closure —— 脚本状态管理
- `/inject`、`/genraw` —— 提示词工程
- `/sort`、`/fuzzy`、`/regex` —— 数据处理
