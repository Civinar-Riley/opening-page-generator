## 📖 项目简介

为 [SillyTavern](https://github.com/SillyTavern/SillyTavern)（酒馆）角色卡制作**开场页组件**的本地可视化工具：把欢迎标题、粒子动效、开场白选择、漫画阅读器等区块拖拽编排成页，导出**自包含单文件 HTML** 贴进 `first_mes`，由酒馆助手（TavernHelper / JS-Slash-Runner）在聊天里渲染。

- **不写代码**：25 种区块 + 59 个可复用组件 + 12 套官方模板，拖拽即所得，改文案改图片即可出成品；
- **纯本地运行**：无服务端、零运行时依赖，工程数据只存浏览器 localStorage，数据不出本机；
- **贴进酒馆就能用**：两种导出格式覆盖开场白 / 正则脚本；
- **AI 也能直接编排**：随 Release 分发 `opg` 技能包，ZCode / Claude Code 等 AI 编码助手凭一份工程 JSON 直接产出成品，无需打开可视化界面。

| 区块类型 | 复用组件 | 官方模板 | 页面主题 | 工具主题 |
|:---:|:---:|:---:|:---:|:---:|
| **25** 种 | **59** 个 | **12** 套 | **6** 套 | **7** 套 |

| 🎛 区块预设 | 欢迎标题 / 引言 / 随机事件 / 骰子 / 入场闸门 5 类内置常用风格，一键套用 |
| 🧱 组件库 | 59 个可复用组件（7 大分类 + 搜索弹窗）——对话气泡、手机聊天窗、终端窗口、监护仪、求签占卜、翻转人物卡……点击追加到自由 HTML 区 |
| 📐 官方模板 | 12 套成品布局，新建工程时一键套用完整排版 |
| 📥 多路导入 | 新建工程弹层支持「从角色卡导入」（PNG / JSON / CHARX，V1/V2/V3 自动识别，映射预览勾选确认，酒馆内可选同时创建角色卡）与「从导出 HTML 反向导入」（粘贴本工具产物：本版本导出自带配置快照**完整还原**，旧版导出轻量恢复并逐区块标注按默认项，认不出的段落原样进自由 HTML 区待认领） |
| 📚 标题库 | 开场白区块带可编辑的标题库草稿（每行 序号｜标题｜描述，手动维护），酒馆内打开工具可一键写入世界书（书不存在自动建，同名条目两步重建不动其它条目，position 支持 outlet） |
| 📸 工程快照 | 顶栏「📸 快照」把当前工程完整副本手动存进浏览器 IndexedDB（与 localStorage 分开存储），恢复生成新工程不覆盖现有数据，最多 20 份自动删最旧——localStorage 之外的回退底 |
| 🖼 粘贴图片压缩 | 截图/复制的图片直接 Ctrl+V 进输入框，先在本地 canvas 限宽压缩（WebP/JPEG 到约 180KB 内）再入库，避免超大 base64 撑爆 localStorage；已足够小的图与 GIF 原样保留 |
| 🎨 双主题体系 | 6 套页面主题（紫夜幻金 / 荆棘王室 / 狐火缘日 / 蓝电义体 / 渊语回廊 / 档案机）：全部带独立材质、字体、配色与动效，悬停试穿点击套用，旧工程不自动换肤；另有 7 套工具主题（暖铜金 / 星夜 / 蓝图 / 磷光 / 深海 / 绯幕 / 月岩，顶栏切换并记忆，仅改变工具界面） |
| 🔤 宏支持 | `{{random}}` `{{roll}}` `{{setvar}}` `{{isotime}}` 等酒馆宏自动包装与预览，随机结果带缓存防预览闪变 |

### 入口三 · 「导出」页 —— 三种格式 + 导出自检

| 特性 | 说明 |
| :--- | :--- |
| ① 开场白版 | 完整 HTML 文档 + 代码围栏，整段贴进 `first_mes` 或 `alternate_greetings`（酒馆助手只渲染「代码块内 + 含 body 标签」的代码） |
| ② 标记 + 正则脚本版 | 生成可直接导入酒馆的正则脚本 JSON：把标记文本贴进开场白 / 世界书条目，由正则替换为完整页面代码 |
| ⚠️ 兼容审查报告 | 导出自检覆盖 `</script>` 逃逸、vw/vh 基准、`position:fixed`、Google Fonts 等已知坑，属提示级清单，不阻断导出 |
| 🖼 图片连通性 | 付印审读区对图库 / 漫画（封面+页）/ 头像 / 主题背景 / 自由 HTML 里的图片 URL 逐个 `Image()` 探测（8 秒超时单独标注「可能只是慢」），失效仅提示不阻断 |
| 💾 代码处理 | 导出代码带语法高亮，长代码预览截断显示，复制 / 下载为完整内容 |

## 📦 安装

**环境要求**

- **使用工具本体**：任意现代浏览器（Chrome / Edge / Firefox），无需安装任何依赖
- **在酒馆内渲染产物**：[SillyTavern](https://github.com/SillyTavern/SillyTavern)（酒馆）+ 酒馆助手扩展（TavernHelper / JS-Slash-Runner），建议更新到较新版本
- **从源码构建**：Node.js ≥ 18（构建依赖 esbuild 的环境要求）+ npm

**安装步骤（直接使用，推荐）**

1. 打开 [GitHub Releases](https://github.com/Civinar-Riley/opening-page-generator/releases/latest)，下载最新版 `opg-vX.X.X.html`
2. 双击该文件，用浏览器打开，即可开始编排
3. 编排完成后在「导出」页复制开场白版代码，贴进角色卡的 `first_mes` 或 `alternate_greetings`
4. 酒馆内需已安装酒馆助手（TavernHelper / JS-Slash-Runner）扩展，产物才能被渲染

**安装步骤（从源码构建）**

1. 克隆仓库并安装依赖：`npm install`
2. 构建产物：`npm run build`（自动压缩，构建后自动跑静态冒烟）
3. 打开 `dist/index.html` 使用；改动 `src/` 时可用 `npm run watch` 自动重建（不压缩，便于断点调试）
4. 提交前跑完整闭环：`npm test`（vitest 单元测试）→ `npm run lint`（零依赖 lint）→ `npm run smoke`（静态 + 无头浏览器双冒烟）

> ⚠️ 开发版 `src/index.html` 使用 ES Modules，直接双击会被浏览器 CORS 拦截，请使用构建产物或本地静态服务器。
>
> ⚠️ 每个 Release 挂三个资产：`opg-vX.X.X.html` 为工具本体（单文件，下载即用）；`opg-nh-helper-vX.X.X.zip` 为「漫画导入助手」小包（免 clone 仓库，解压 → 双击安装协议 → 工具页点启动。**这个 ZIP 不必单独下载**——工具本体已内嵌同一份小包，在「📚 漫画导入」页点「📦 导出助手小包」即可导出，两者逐字节一致）；`opg-skill-vX.X.X.zip` 为 AI 技能包（解压进 ZCode / Claude Code 等的技能目录，AI 凭工程 JSON 直接产出开场页，本机需 Node 18+）。push `v*` tag 会自动触发完整流水线（lint → 测试 → 构建 → 双冒烟 → 建 Release）。
>
> ⚠️ 工具页离线打开时飞书字体 CDN 加载失败会回落系统字体，不影响任何功能；无 API 环境下组件自动降级显示占位内容。

## 🚀 使用指南

| 场景 | 操作 |
| :--- | :--- |
| **从零做一张开场页** | 「模板配置」页新建工程 → 选 12 套官方模板之一套用布局 → 逐区块改文案 / 图片 → 「预览」页切 📱 / 🖥 与 🌙 / ☀️ 复核 → 「导出」页复制①开场白版 |
| **贴进角色卡** | 复制①开场白版整段（保留代码围栏与 body 标签）→ 酒馆角色卡 `first_mes` / `alternate_greetings` |
| **做开场白选择器** | 配置页加「开场白选择」区块 → 选卡片式 / 列表式 / 封面墙 → 逐项填绑定标题 + 封面图与联动音轨（「📋 按占位列表补标题」可一键补）→ 按需开排除标签过滤与人名提取 → 导出 |
| **从角色卡开工** | 顶栏「新建」→「📥 从角色卡导入」→ 选 PNG / JSON / CHARX（V1/V2/V3 自动识别）→ 勾选映射（开场白 / 角色简介）→ 生成工程后微调 → 导出 |
| **把已导出的开场页导回工程** | 顶栏「新建」→「🧩 从导出 HTML 反向导入」→ 粘贴产物完整文档 → 勾选认回的区块 → 生成工程（本版本导出经配置快照完整还原；旧导出轻量恢复并标注按默认项；认不出的段落原样进自由 HTML 区待认领） |
| **把一本漫画填进开场页** | 「📚 漫画导入」页启动本机服务 → 贴 nhentai 画廊链接抓全本 → 勾选页面 / 去尾 N 页 → 一键写入漫画区块 → 「预览」页核对 |
| **用正则方案嵌入** | 「导出」页②生成「标记 + 正则脚本」→ 标记文本贴进开场白或世界书条目 → 酒馆「扩展 → 正则」导入下载的 JSON |
| **让 AI 帮忙出内容** | 「AI 助手」页填 OpenAI 兼容 URL + Key → 生成自由 HTML 内容与主题配色 |
| **让 AI 直接编排整页（skill）** | Releases 下载 `opg-skill-vX.X.X.zip` 解压到 AI 编码助手技能目录（如 `~/.claude/skills/` 或 `.zcode/skills/`）→ 对 AI 说「用 opg 给某某角色生成一个开场页」——AI 走 `--template` / `--new` 起步、改工程 JSON、`--fenced` 出成品（本机需 Node 18+） |
| **换工具界面配色** | 顶栏主题下拉：暖铜金 / 星夜 / 蓝图 / 磷光 / 深海 / 绯幕 / 月岩，选择自动记忆；仅改变工具界面，不影响导出页面 |
| **重置全部本地数据** | 顶栏「⟲ 重置」三次确认（清空工程 / 模板 / 主题偏好，建议先「导出工程」备份） |

## ❓ 常见问题

**Q：双击 `src/index.html` 打开是空白？**
A：开发版使用 ES Modules，直接双击会被浏览器 CORS 拦截。请改用构建产物 `dist/index.html`，或起一个本地静态服务器。

**Q：产物贴进酒馆后没有样式 / 区块不显示？**
A：产物依赖酒馆助手（TavernHelper / JS-Slash-Runner）扩展渲染；未安装或当前环境无对应 API 时，组件会自动降级显示占位内容，属预期行为。

**Q：开场页里的字体或图标会请求外部资源吗？**
A：产物自包含，样式与脚本全部内联，图标使用 emoji / 内联 SVG。仅工具页本身在离线打开时飞书字体 CDN 会加载失败并回落系统字体，不影响任何功能。

**Q：我的工程数据存在哪？会被上传吗？**
A：全部存在浏览器 localStorage（`openingPageGen_*` 键，每个工程独占一个键，保存时只写改动过的工程），本工具无服务端、数据不出本机。粘贴超过 200 KB 的 base64 内嵌图片时会提示改用图床链接，保存失败时提示会指出体积最大的区块。换浏览器或清理站点数据会丢失，重要工程请先用「导出工程」备份。

**Q：AI 助手的 API Key 会写进导出的页面吗？**
A：不会。Key 默认只存本机；勾掉「在本机记住 Key」后仅本次会话使用、不写入 localStorage；导出工程时 Key 会被自动剔除。

**Q：想把已导出的开场页 HTML 导回工程继续编辑？**
A：新建工程弹层的「🧩 从导出 HTML 反向导入」贴入产物即可。本版本导出的页面内嵌配置快照，勾选的区块连同排版开关/颜色/字号/列数/封面音轨绑定完整还原（无损往返）；旧版导出轻量恢复——排版与样式类配置不随产物保留，导入预览会逐区块标注，按默认值回填。认不出的段落原样进自由 HTML 区待手动认领，解析纯本地进行。

**Q：构建报「产物体积超预算」？**
A：`build.js` 设有体积预算线：超 1024 KB 告警、超 1280 KB 构建失败（CI 会挡下）。请精简产物，或显式调高预算并把理由写进提交说明。

**Q：漫画导入抓不到内容？**
A：抓取由本机服务完成（`npm run nh-serve`，只监听 `127.0.0.1`）。Node 不走系统代理，请在页面「抓取代理」填入本机代理地址（Clash 默认 `http://127.0.0.1:7890`）。若不想 clone 仓库，在「📚 漫画导入」页点「📦 导出助手小包」拿到 ZIP（工具本体已内置，无需另找下载），解压后双击「安装协议.bat」再回来点启动（仍需本机装有 Node 18+）。

**Q：反馈问题时需要提供什么？**
A：请走 [Issue 模板](https://github.com/Civinar-Riley/opening-page-generator/issues/new/choose)，带上工具版本（顶栏 logo 右侧或「使用说明」页顶部的「vX.X.X · 构建于 日期」）、酒馆助手版本与使用环境。
