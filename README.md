# 企鹅的酒馆开场页生成器 v1.9.0

为 [SillyTavern](https://github.com/SillyTavern/SillyTavern)（酒馆）角色卡生成开场页组件的本地可视化工具。

通过拖拽、配置区块，一键生成可嵌入酒馆的开场页 HTML 代码，无需手写。

## 功能特性

- **可视化编辑**：拖拽排列区块、一键复制区块、实时预览效果（📱手机 / 🖥PC 宽度、🌙暗色 / ☀️亮色底模拟）
- **撤销/重做**：Ctrl+Z 撤销、Ctrl+Shift+Z / Ctrl+Y 重做，最多 20 步历史；Ctrl+S 立即保存
- **区块搜索**：按名称实时筛选区块，快速定位
- **全局搜索替换**：跨区块批量查找替换（含角色/图片/曲目/问答/装饰花纹等子项），支持逐个定位后单处或全部替换
- **区块预设**：欢迎标题/引言/随机事件/骰子内置常用风格模板，一键套用
- **触屏支持**：长按把手拖拽排序，移动端可用
- **丰富区块类型**：欢迎标题、装饰背景、粒子动效、开场引言、动态时钟栏、随机事件、掷骰判定、倒计时、时间线/进度、角色简介、问答折叠、图片展示、音频 BGM、开场白选择、分隔装饰线、免责声明、作者的话、自由 HTML，共 18 种
- **宏语法支持**：`{{random::}}`、`{{roll::}}`、`{{setvar}}/{{getvar}}`、`{{isotime}}` 等酒馆宏自动包装与预览；random/pick 选项支持一层花括号（如 `{{random::a{b}::c}}`）
- **页面主题预设**：5 套成品配色（紫夜幻金/荆棘王室/狐火缘日/蓝电义体/渊语回廊）一键套用
- **官方完整模板**：赛博 AI 连接风、奇幻酒馆风、敦煌秘境·丝路旅记、雾都疑云·维多利亚侦探、锈壤纪元·废土拾荒、云上航线·蒸汽飞艇、百鬼夜市·灯笼街、黄沙驿站·赏金正午、雾港低语·深潜归航等，新建工程时一键套用完整布局
- **组件库**：26 个可复用组件——对话气泡组、物品栏卡片、终端窗口、手写信笺、任务告示板、章节标题头、评价卡、日期事件卡、打字机文本框、多标签页等，点击追加到自由 HTML 区
- **五套工具主题**：暖铜金（默认）/ 星夜 / 蓝图 / 磷光 / 深海，顶栏下拉选择并记忆
- **工程管理**：本地存储、导入导出、多工程切换
- **工厂重置**：顶栏「⟲ 重置」三次确认后清空全部本地数据（工程/模板/预设/主题偏好），恢复初始状态——重置前建议先「导出工程」备份
- **纯文本状态栏生成器**：自定义字段一键生成 世界书条目 + 正则美化 + 开场白后缀 三件套，行式/标签块两种模式；美化面板提供六套布局变体（夜宴酒牌/紧凑网格/手稿扉页/黑客终端/冰晶玻璃/杂志排版）+ 布局微调（列数/间距/边框/圆角/标题栏样式/行动选项位置）+ 样式统筹（面板背景/标签值颜色字体/行动选项三色）；内置 6 套美化预设，行动选项点击填入输入框，附正则测试沙盒
- **AI 助手（可选）**：接 OpenAI 兼容接口生成自由 HTML 区内容与主题配色；填好 URL 与 Key 后可一键拉取模型列表（下拉选择，只读 /models 不发送对话请求）；Key 仅明文本地保存，导出工程自动剔除
- **多种导出格式**：开场白版、标记+正则脚本版，适配不同嵌入场景；导出代码带语法高亮，长代码预览截断显示（复制/下载为完整内容）

## 快速开始

### 直接使用（推荐）

下载 `dist/index.html`，双击打开即可使用，无需安装任何依赖。

### 从源码构建

```bash
# 1. 安装依赖
npm install

# 2. 构建（正式构建自动压缩 JS/CSS；watch 模式不压缩便于调试）
npm run build

# 3. 运行单元测试（宏引擎 / 状态栏 / 生成引擎 / 数据迁移 / 搜索替换 / 字体检测 / 工具函数）
npm test

# 4. 交付前零依赖 lint（未使用 import / 未定义标识符 / localStorage key 前缀 / console.log 残留）
npm run lint

# 5. 产物在 dist/ 目录下
```

开发时可使用 watch 模式，修改 `src/` 后自动重新构建：

```bash
npm run watch
```

## 自定义

- **AI 协作**：改动前先参考根目录 `AGENTS.md`（硬约束清单与常见任务配方）；生成脚本的酒馆助手 API 契约见 `src/js/gen/TAVERN_API.md`
- **添加组件**：编辑 `src/js/defs.js` 中的 `COMP_LIB`
- **添加主题预设**：编辑 `src/js/defs.js` 中的 `THEME_PRESETS`
- **添加区块类型**：编辑 `src/js/defs.js` 的 `BLOCK_DEFS` + `BLOCK_ORDER`，渲染逻辑在 `src/js/gen/` 目录

## 注意事项

- 开发版 `src/index.html` 使用 ES Modules，直接双击会被浏览器 CORS 拦截，请使用构建产物或本地静态服务器
- 构建产物 `dist/` 是自包含单文件，可直接分发给酒馆用户
- 酒馆需安装「酒馆助手（TavernHelper / JS-Slash-Runner）」扩展；无 API 环境下组件自动降级显示占位内容
