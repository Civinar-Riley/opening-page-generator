# slots/ —— 产物模板插槽

这个文件夹存放**导出产物的模板文件**：替换文件内容 → `npm run build`（watch 模式自动重建）→ 导出页即时生效。改模板不需要碰任何 JS 代码。

## back-home.json —— 「返回开场页」角色脚本模板

导出页 ③「返回开场页脚本」生成的角色脚本 JSON 以此文件为内置模板。字段契约：

| 字段 | 必需 | 说明 |
|------|:---:|------|
| `type` | ✅ | 固定 `"script"`（酒馆助手角色脚本格式） |
| `content` | ✅ | 脚本 JS 源码字符串（IIFE，自带守卫与降级） |
| `name` | 可选 | 脚本名；可用 `{{工程名}}` 占位符，导出时替换为当前工程名。缺省回落 `返回开场页-{工程名}` |
| `enabled` | 可选 | 缺省 `true` |
| `info` | 可选 | 脚本描述，缺省空串 |
| `button` / `data` / `export_with` | 可选 | 酒馆助手格式字段，缺省回落标准值 |

注意：

- `id` 每次导出自动重新生成（防止脚本库内撞 ID），模板里的 `id` 只是占位
- `content` 是**字符串**不是对象——直接改 JSON 里转义过的 JS 源码即可；本地调试可在 Node 里 `new Function(JSON.parse(...).content)` 快速验语法
- 换完记得跑 `npm test`（测试含模板契约守卫与语法解析），再 `npm run build`
